# walkthrough — RadioCode.Space (v1 доводка)

Артефакт ИИ-агента по наряду-заданию Архитектора от 2026-07-19.

## Что и зачем меняется

| Область | Было | Стало | Файлы |
|---|---|---|---|
| Ротация плейлиста | наивный `(i+1)%N` и random != current — версии одной композиции могли идти подряд | эпохи с зазором ≥⌊N/2⌋ + round-robin версий, персист в localStorage | `src/lib/rotation.ts`, `src/stores/playerStore.ts` |
| Битрейт на сайте | «320 KBPS HQ», бейджи 320/256 | фактические VBR-значения из ffprobe/mutagen | `src/lib/stations.ts`, `src/app/page.tsx`, `src/app/layout.tsx` |
| Битые названия | 4 названия с mojibake-символами | восстановлены | `src/lib/stations.ts` |

## Ключевые инварианты ротации (проверены автотестом)
- В пределах эпохи каждая композиция играет ровно один раз.
- Между двумя проигрываниями одной композиции — не менее ⌊N/2⌋ других композиций.
- Версии композиции идут round-robin (не предсказуемо v1→v2→v3).
- Состояние переживает перезагрузку страницы.
- Все 596 файлов сохранены; версии не удаляются и не объединяются.

## Артефакты
- `reports/compositions.json` — группировка файлов по композициям (160 групп).
- `reports/suspicious_merges.json` — проверка склеек (3 ложных флага из-за битых названий).
- `reports/bitrate.csv` — измеренный битрейт всех 596 файлов.
- `scripts/test-rotation.ts` — автотест ротации (5000 итераций/станцию).

## Запуск автотеста
```
node --experimental-strip-types scripts/test-rotation.ts
```

## [2026-08-12 09:40] Единая память: полная переписка, дословный слой на сервере, чтение памяти любого
- **Порог полной памяти 150 000 → 1 000 000 знаков** на всех четырёх сайтах. Замер по боевой базе: людей с памятью 13, самая большая память 354 210 знаков (385 реплик), вторая 311 777 (393). При прежнем пороге полную переписку не получали ровно двое главных собеседников AIfa — чем активнее человек, тем хуже его помнили.
- **Устройство полной памяти перенесено с центра на три сайта**: `fullMemory`, `memoryMap`, бюджеты блоков, `buildFullMemory`, `buildMemoryMap`. На aifa.digital и radiocode.space памяти не было вовсе.
- **Дословный зашифрованный слой пишется на сервере**, внутри `/api/aifa-chat` и `/api/oracle`, общей функцией `appendVerbatim` с защитой от удвоения по отпечатку пары. Раньше он писался запросом из браузера и терялся при закрытии вкладки: в базе не было ни одной записи канала `main`. Проверено: было 0 записей — стало 1, повтор распознан, запись читается личным ключом человека.
- **`/api/admin/memory` на всех четырёх сайтах** — чтение полной переписки ЛЮБОГО человека под `requireAdmin`, каждое чтение пишется в журнал доступа. Такого пути не существовало: единственное чтение архива брало почту из сессии. Проверено: 4 человека из 4 прочитаны полностью, 633 414 знаков, отказов 0.
- **Метки каналов сведены**: чат кабинета слал `main` в смысловой слой и `terminal` в дословный — один разговор ложился под двумя именами. Теперь канал объявлен одной переменной на оба слоя.
- **Вкладка «Моя память» показывает одну ленту** по времени вместо кусков по каналам, источник подписан у каждой реплики.
- **Порядок провайдеров приведён к требуемому**: бесплатное → грант → личный ключ Архитектора. На aifa.works было наоборот (грант тратился раньше бесплатного), у двух спутников бесплатного и гранта не было вовсе.
- **Проверено**: `npm run build` прошёл на всех четырёх сайтах, код возврата 0; `tsc --noEmit` чист; проверка не пустая — заведомая ошибка поймана и снята. Бэкап обеих таблиц памяти снят до правок: 322 825 строк, 660 МБ.

## 2026-08-25 — ночной прогон: деньги, секреты, текст

**Что менялось в этом репозитории:**

1. **Привратник на платном Grok.** Перебраны ВСЕ обращения к платным
   поставщикам в четырёх живых деревьях — 47 штук. К `api.x.ai` (карта
   Архитектора) — 10; привратник `платныеРазрешены()` стоял у девяти.
   Десятый закрыт. Проверка: повторный перебор даёт 0 без привратника.

2. **Озвучка докладывает сторожу расходов.** Платная ступень Grok TTS имела
   месячный потолок знаков, но почасовому сторожу не докладывала. Потолок
   ловит перерасход за месяц, сторож — пожар за час; нужны оба. Ставка Grok
   TTS неизвестна, поэтому `grok-voice` считается по нулевой ставке: пишутся
   знаки и число вызовов, а не выдуманные доллары.

3. **Фамилия Архитектора приведена к GALATIN** по его прямому слову от
   24.08.2026. Всего по четырём репозиториям 232 замены в 57 файлах.

4. **Исправлена бессмыслица в условиях.** Слово `spipráctica` (140 вхождений
   в 26 файлах на четырёх сайтах и двух языках) — след давней глобальной
   замены `ritual` → `práctica`, сделанной без границы слова: она съела
   середину слов `spiritual` и `espiritual`. Восстановлено.

5. **Страж сайтов научился видеть форматы наших сервисов** — Vercel, Neon
   API, Resend, Telegram, Slack, Stripe, AWS. До этого он знал только шесть
   форматов и не знал ровно тех, на которых стоит проект.

**Как проверялось.** Проверка типов — 0 ошибок в каждом дереве. Сборка — 4 из
4. Валидатор терминологии — пройден везде. Рендер живых страниц снаружи, а не
код ответа: старого написания фамилии 0, `spipráctica` 0, `Spiritual` на месте.

**Что осталось и ждёт Архитектора:** сменить токен Vercel (три минуты,
`vercel.com/account/tokens`) — живой токен найден в двух файлах Мозга.
